## Lab Activities

The 8 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Validate the Northwind Request Intake and Create an Automated Acknowledgement](labs/lab-01-validate-the-northwind-request-intake-and-create-an-automated-acknowledgement.md) | A validated per-learner SharePoint list named C903 Process Requests, an automated cloud flow named C903-01-Acknowledge-New-Request, and a saved evidence record for RequestID NW-1006 |
| **2** | [Build a Scheduled Reminder and Diagnose a Controlled Failure](labs/lab-02-build-a-scheduled-reminder-and-diagnose-a-controlled-failure.md) | A scheduled cloud flow named C903-02-Remind-Due-Requests, evidence rows for normal, empty, duplicate, and controlled-failure cases, and a recorded primary and backup owner |

### Topic 2 — Build Approval Flows with Power Automate

| # | Activity | Outcome |
|---:|----------|---------|
| **3** | [Build a Priority Approval with Complete Outcome and Recovery Paths](labs/lab-03-build-a-priority-approval-with-complete-outcome-and-recovery-paths.md) | An automated cloud flow named C903-03-Approve-High-Priority-Request with explicit non-High actions, three approval cases, a default case, serial Try/Catch/Finally scopes, and five path tests |
| **4** | [Create and Traverse a Conditional Dataverse Business Process Flow](labs/lab-04-create-and-traverse-a-conditional-dataverse-business-process-flow.md) | An active C903 Request Lifecycle business process flow in the C903 Northwind Automation solution, published in C903 Request Manager, with complete High and Normal path evidence |

### Topic 3 — Build Flows to Manage User Information

| # | Activity | Outcome |
|---:|----------|---------|

| **6** | [Block Calendar Time with Validation and Duplicate Prevention](labs/lab-06-block-calendar-time-with-validation-and-duplicate-prevention.md) | An instant cloud flow named C903-06-Block-Follow-Up-Time, one calendar event for NW-1007, a persisted Event ID, and evidence for six validation and duplicate cases |

| # | Activity | Outcome |

| **8** | [Recover the Same Integration Run and Complete Operational Handover](labs/lab-08-recover-the-same-integration-run-and-complete-operational-handover.md) | A final 07B flow with tested serial Try/Catch/Finally behaviour, same-record recovery evidence for NW-1099, NW-1010 regression evidence, approved co-owners, and a Reviewed operations runbook |

## About

This repository contains the complete lab and courseware package for **PL-7002 Create and Manage Automated Processes by using Power Automate** (**C903**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Validate the Northwind Request Intake and Create an Automated Acknowledgement** to **Recover the Same Integration Run and Complete Operational Handover**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **8 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Power Apps · Power Automate · Microsoft SharePoint · Microsoft Dataverse · SQL · Microsoft Outlook** and the supporting resources supplied in the repository.
- Begin with **Validate the Northwind Request Intake and Create an Automated Acknowledgement** and finish with **Recover the Same Integration Run and Complete Operational Handover**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **Power Apps · Power Automate · Microsoft SharePoint · Microsoft Dataverse · SQL · Microsoft Outlook**. Follow the setup and access notes in each lab.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C903---PL-7002-Create-and-Manage-Automated-Processes-by-using-Power-Automate.git
cd C903---PL-7002-Create-and-Manage-Automated-Processes-by-using-Power-Automate
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–8 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
