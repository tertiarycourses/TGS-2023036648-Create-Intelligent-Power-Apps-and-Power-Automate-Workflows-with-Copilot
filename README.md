## Build

From Git Bash on Windows:

```bash
COURSE_REPO="$(pwd)" bash ".agents/skills/non-wsq-courseware-build/build/build_courseware.sh"
```

Generated artifacts are written to `courseware/`. The Learner Guide Markdown mirror is written to the repository root, and the connected practical activities are written to `labs/`.
