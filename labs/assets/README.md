# C903 Lab Assets

All files in this folder contain synthetic training data for the connected Northwind Operations scenario.

| File | Purpose |
|---|---|
| `process-requests.csv` | Five baseline SharePoint request records |
| `request-schema.md` | Exact list, Dataverse, and cross-system field contract |
| `test-evidence-template.csv` | Evidence register used by all eight labs |
| `correlation-register-template.csv` | Cross-system identifier register |
| `setup-automation-audit.sql` | Idempotent training SQL table setup and verification query |
| `operations-runbook-template.md` | Final monitoring, recovery, ownership, and handover record |
| `c903-starter-solution-package-v1.0.md` | Versioned inventory of every inactive starter flow and placeholder |
| `trainer-provisioning-checklist.md` | Per-learner pre-class isolation, connection, and starter-readiness checks |

Use only the trainer-assigned isolated SharePoint site, Power Platform environment, calendar, and SQL database or schema. Fixed `NW-*` identifiers must never be shared across learners. Do not replace these synthetic files with production exports.
