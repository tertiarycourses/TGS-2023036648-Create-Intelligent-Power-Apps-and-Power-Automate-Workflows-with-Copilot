# Labs — Create Intelligent Power Apps and Power Automate Workflows with Copilot

**Course code:** TGS-2023036648  
**Provider:** Tertiary Infotech Academy Pte Ltd (UEN 201200696W)  
**TSC:** Applications Integration (ICT-DIT-3003-1.1)

Twenty-six hands-on labs run across the four days of *Create Intelligent Power Apps and Power Automate Workflows with Copilot*. They build one continuous story: you validate the environment, let Copilot generate a first app and a first flow, then hand-build a pet-boarding solution on Dataverse, automate it with cloud flows and Copilot Studio agents, model the Contoso Real Estate domain as a model-driven app, ship it to a second environment as a managed solution, and finish by diagnosing four seeded integration faults.

Each lab folder contains a `README.md` with the full click-path steps and a `mock-data/` folder with Singapore-flavoured business data (SGD amounts, local names, addresses and +65 numbers). The data is internally consistent across labs — the same kennels, pets, agents and properties carry through — so a lookup imported in one lab still resolves in the next.

Work the labs in order. Later labs depend on the tables, apps and flows built earlier.

## Before you start

- Sign in to [make.powerapps.com](https://make.powerapps.com) with the training account your trainer assigns.
- Use the **same environment** (Dev One, or whichever the trainer names) for every lab. An environment mismatch is the single most common cause of "my table has disappeared" in this course.
- The environment must have a **Dataverse database** provisioned. Confirm this in Lab 01 before going further.
- Labs 11 and 25 need a second environment and a local toolchain (Node.js LTS, .NET SDK, Power Platform CLI). Install these before Day 2 if you are working ahead.
